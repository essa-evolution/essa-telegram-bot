# 05_ESSA_CORE_RELATIONSHIPS

## Статус документа

Этот документ описывает связи между основными сущностями ESSA.

Он определяет не сами сущности, а отношения между ними.

Документ не описывает реализацию, интерфейсы, базы данных, API или код.

Он описывает стратегическую карту связей внутри экосистемы ESSA.

Документ следует после:

- `00_ESSA_CORE_PHILOSOPHY`;
- `01_ESSA_CORE_ECOSYSTEM`;
- `02_ESSA_CORE_LIFECYCLE`;
- `03_ESSA_CORE_PRINCIPLES`;
- `04_ESSA_CORE_ENTITIES`.

Если `04_ESSA_CORE_ENTITIES` отвечает на вопрос "что существует в ESSA", то `05_ESSA_CORE_RELATIONSHIPS` отвечает на вопрос "как сущности ESSA связаны между собой".

## Центральная идея

Экосистема ESSA представляет собой живую сеть взаимосвязанных сущностей.

Каждая сущность существует не изолированно, а взаимодействует с другими.

Человек формирует намерения.

Намерения становятся направлением будущих идей.

Идеи становятся проектами.

Проекты создают контент, активы и публикации.

Команды, агенты, знания, компании, сообщества и партнёры помогают проектам развиваться.

Все связи ESSA должны помогать человеку двигаться от идеи к реализации.

## Основные связи

### Человек

Человек является центром сети отношений ESSA.

Человек:

- имеет цифровую личность;
- формирует намерения;
- рождает идеи;
- создаёт проекты;
- взаимодействует с агентами;
- входит в команды;
- может создавать компании;
- публикует результаты;
- получает знания;
- создаёт знания;
- становится частью сообщества;
- сотрудничает с партнёрами;
- развивает активы;
- открывает новые направления.

Связи человека с другими сущностями должны усиливать его способность создавать, проявляться и развиваться.

### Намерение

Намерение рождается у человека.

Намерение:

- соединяет человека с будущей идеей;
- формирует направление идеи;
- может привести к нескольким идеям;
- становится отправной точкой будущего проекта;
- может изменяться по мере развития человека;
- может усиливаться, ослабевать или исчезать без реализации;
- помогает отличить случайную мысль от выбранного направления движения.

Намерение не является готовым проектом.

Намерение показывает, что человек внутренне выбрал направление, которое может стать идеей, проектом и проявлением.

### Цифровая личность

Цифровая личность принадлежит человеку.

Цифровая личность:

- представляет человека внутри ESSA;
- используется в проектах;
- сопровождает взаимодействие с агентами;
- хранит историю развития;
- отражает индивидуальность автора;
- может быть связана с голосом, визуальной идентичностью, стилем и памятью;
- может участвовать в публикациях, production-проектах и avatar/video-направлениях;
- должна использоваться только с согласием владельца.

Цифровая личность не должна отделяться от человека как самостоятельный объект владения системы.

### Идея

Идея принадлежит человеку и может вырастать из намерения.

Идея:

- появляется из намерения, мечты, вопроса, желания, проблемы или наблюдения;
- становится проектом;
- может объединяться с другими идеями;
- может разделяться на несколько проектов;
- развивается в процессе реализации;
- может возвращаться к человеку в новой форме после опыта и роста.

Связь идеи с человеком должна сохранять авторство и исходный смысл.

### Проект

Проект создаётся человеком.

Проект:

- возникает из идеи;
- может включать команду;
- использует агентов;
- создаёт контент;
- формирует активы;
- приводит к публикациям;
- может стать частью компании;
- может использовать знания;
- может быть связан с цифровой личностью;
- может привлекать партнёров;
- может создавать сообщество вокруг результата.

Проект является центральной рабочей точкой, где идея становится реальностью.

### Агент

Агент помогает человеку.

Агент:

- выполняет задачи проекта;
- задаёт вопросы;
- помогает структурировать идею;
- создаёт черновики;
- взаимодействует с другими агентами;
- работает внутри пространства или workflow;
- использует знания;
- может помогать команде;
- не является владельцем результатов.

Агент должен быть связан с человеческой целью, а не действовать как автономный владелец смысла.

### Команда

Команда объединяет людей и проекты.

Команда:

- совместно реализует идеи;
- использует возможности ESSA;
- включает роли, ответственность и вклад участников;
- может взаимодействовать с агентами;
- может быть частью компании;
- может формироваться вокруг одного проекта или направления;
- может создавать контент, активы и публикации.

Команда усиливает человека там, где проект требует совместного действия.

### Компания

Компания состоит из проектов, команд, процессов и направлений.

Компания:

- объединяет проекты;
- объединяет команды;
- взаимодействует с клиентами;
- взаимодействует с партнёрами;
- создаёт контент;
- создаёт активы;
- публикует результаты;
- развивает экономику ценности;
- может иметь несколько цифровых личностей, ролей и рабочих пространств;
- развивается внутри экосистемы.

Компания в ESSA должна быть связана с ценностью, которую создают люди, а не только с коммерческой формой.

### Контент

Контент создаётся проектами.

Контент:

- может становиться активом;
- может публиковаться;
- может использоваться повторно с соблюдением авторских прав;
- может поддерживать компанию, автора, сообщество или направление;
- может порождать новые идеи;
- может быть частью медиапакета, сайта, курса, книги, видео, песни или документа.

Контент является проявлением идеи в материальной или цифровой форме.

### Актив

Актив принадлежит проекту, автору, команде или компании.

Актив:

- может использоваться повторно;
- помогает создавать новые проекты;
- сохраняет накопленную ценность;
- может быть шаблоном, промптом, изображением, сценарием, voice-пакетом, дизайном, компонентом, библиотекой или knowledge-пакетом;
- должен сохранять связь с авторством, правами и контекстом использования.

Активы помогают ESSA не начинать каждый проект с нуля.

### Публикация

Публикация является проявлением проекта.

Публикация:

- выводит результат во внешнюю или внутреннюю среду;
- может распространяться внутри ESSA;
- может распространяться за пределами ESSA;
- может приводить к аудитории, клиентам, партнёрам, командам и новым идеям;
- должна сохранять авторство и контекст проекта.

Публикация связывает созданный результат с миром.

### Сообщество

Сообщество объединяет людей.

Сообщество:

- способствует сотрудничеству;
- помогает обмену знаниями и опытом;
- может формироваться вокруг проекта, направления, автора, компании или ценности;
- может помогать развитию новых идей;
- может поддерживать участников на разных этапах жизненного цикла ESSA.

Сообщество делает экосистему живой, потому что соединяет людей вокруг смысла.

### Партнёр

Партнёр связан с человеком, проектом, командой, компанией или ESSA.

Партнёр:

- усиливает реализацию;
- приносит экспертизу;
- может предоставлять ресурсы;
- может участвовать в развитии проекта;
- может помогать публикации, обучению, продвижению, сопровождению или проверке качества;
- должен уважать авторство, согласие и ценность проекта.

Партнёрство должно строиться на доверии и понятных правилах.

### Знание

Знание связано со всеми сущностями ESSA.

Знание:

- помогает человеку принимать решения;
- поддерживает агентов;
- сохраняет опыт проектов;
- помогает командам;
- усиливает компании;
- делает активы более полезными;
- помогает новым проектам быстрее стартовать;
- должно сохранять контекст, источник и назначение.

Знание является памятью экосистемы, но не заменяет живой выбор человека.

### Экосистема

Экосистема объединяет все связи.

Экосистема:

- соединяет людей, идеи и проекты;
- связывает пространства, агентов и знания;
- поддерживает команды, компании и сообщества;
- помогает контенту превращаться в активы и публикации;
- создаёт условия для экономики ценности;
- удерживает целостность ESSA.

Экосистема не должна дробиться на несвязанные инструменты.

Она должна развиваться как сеть, где каждая связь помогает человеку проявиться.

## Общий граф отношений ESSA

```text
Человек
  → имеет → Цифровая личность
  → формирует → Намерение
  → через намерение рождает → Идея
  → создаёт → Проект
  → входит в → Команда
  → может создавать → Компания
  → становится частью → Сообщество

Намерение
  → формирует направление → Идея
  → может привести к → несколько Идей
  → становится отправной точкой → Проект
  → может изменяться вместе с → Человек

Идея
  → превращается в → Проект
  → может объединяться с → Идея

Проект
  → использует → Агент
  → создаёт → Контент
  → формирует → Актив
  → проявляется через → Публикация
  → может входить в → Компания
  → может собирать → Команда

Контент
  → может стать → Актив
  → может стать → Публикация

Знание
  → поддерживает → Человек / Агент / Проект / Команда / Компания

Экосистема
  → объединяет → все сущности и связи
```

## Главный путь развития ESSA

```text

Намерение

↓

↓

Проект

↓

Контент

↓

Актив

↓

Публикация

↓

Развитие
```

## Главный принцип

Все связи внутри ESSA существуют для одной цели:

помочь человеку пройти путь от идеи к её реализации через сотрудничество, знания, технологии и поддержку.

Если связь не помогает человеку, проекту или экосистеме развиваться, она должна быть пересмотрена.

Если связь усиливает проявление, сотрудничество, авторство и ценность, она может быть частью ESSA.

## Архитектурное значение

`05_ESSA_CORE_RELATIONSHIPS` должен использоваться при проектировании новых модулей, пространств и workflows.

Перед добавлением новой связи нужно понять:

- какие сущности она соединяет;
- кто является владельцем или ответственным;
- как сохраняется авторство;
- как соблюдается согласие;
- какую ценность создаёт связь;
- помогает ли она жизненному циклу ESSA;
- не создаёт ли она зависимости, которая удерживает человека против его интересов.

ESSA должна быть сетью ценности, а не сетью принуждения.

## Завершение

Этот документ фиксирует стратегическую карту связей ESSA.

Сущности важны, но связи между ними делают экосистему живой.

Все будущие связи должны усиливать человека, проект, сотрудничество и развитие экосистемы.
