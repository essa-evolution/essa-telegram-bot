# 09 Vector User Memory

## Purpose
Vector User Memory is the future semantic memory layer for finding relevant past context by meaning, not only by exact words.

## What It Enables
- recall similar moments;
- connect recurring themes;
- retrieve project context;
- surface useful past decisions;
- support long-term continuity.

## Current Related System
ESSA Knowledge Base already uses vector retrieval for documents through Supabase chunks and embeddings.

## Future Direction
User memory can later use a similar vector approach for personal context, with strict privacy and relevance rules.

## Boundary
Semantic recall must be careful. Navigator should retrieve only what helps the current interaction.
