# 08 Summary Memory

## Purpose
Summary Memory compresses long dialogues into clear continuity.

## What A Summary Keeps
- what happened;
- what was decided;
- what changed;
- what remains open;
- where to continue.

## Use In Dialogue
Navigator uses summaries to reduce cognitive load and help the person feel the path is held.

## Future Direction
Summaries should become automatic checkpoints after long sessions or completed stages.

## Boundary
Summaries must not erase emotional meaning. They should preserve the human thread, not only the tasks.
