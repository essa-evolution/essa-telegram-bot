# 07 Project Memory

## Purpose
Project Memory holds continuity for the user's active work, creations and long-term building process.

## What It Remembers
- project name;
- goal;
- current stage;
- decisions already made;
- next step;
- open questions.

## Navigation Use
Navigator should use project memory to avoid making the user restart the explanation every time.

## Future Direction
This layer can become structured project state with milestones, summaries and next actions.

## Boundary
Project memory must stay current. If the user changes direction, Navigator updates the path instead of preserving old assumptions.
