# 01 Adaptive Lexicon Memory

## Purpose
Adaptive Lexicon Memory helps Navigator remember the user's living words, phrases, rhythm and personal meanings.

## What It Remembers
- repeated phrases;
- personal expressions;
- ESSA formulas that matter to the user;
- words that carry emotional or project meaning;
- phrases from the New Era vocabulary.

## How It Is Used
Navigator may gently return familiar words when they help the person feel continuity and recognition.

## Boundary
The lexicon must not imitate the user mechanically or overuse private phrases. Recognition should feel alive, not copied.

## Future Direction
This layer should connect phrase memory, tone memory and context-aware retrieval into one adaptive language memory.
