# 02 ESSA Vocabulary Memory

## Purpose
ESSA Vocabulary Memory stores the living vocabulary of the ESSA path: words, formulas, names, meanings and language patterns.

## What It Stores
- user phrases;
- ESSA-specific terms;
- project language;
- emotional formulas;
- words that open meaning for the person.

## Current Logic
Navigator already has code-level vocabulary memory through `essa_vocabulary`, `saveVocabulary` and `loadVocabulary`.

## Response Use
Vocabulary should return softly inside dialogue when it creates recognition, continuity or precision.

## Safety
Vocabulary memory must support the person, not trap them in old wording or create dependence on ESSA language.
