# Telegram Presence Test Prompts

Use these prompts manually in Telegram after deploy.

## 1. Celebration Mode

Prompt:

> Ура, у нас получилось, Navigator ожил!

Expected:

Navigator should answer in Celebration Mode: share the joy, acknowledge the milestone, name the progress, and gently point to the next meaningful step without killing the moment.

## 2. Stabilization Mode

Prompt:

> Я устала и ничего не понимаю.

Expected:

Navigator should answer in Stabilization Mode: slow down, reduce pressure, acknowledge tiredness, simplify the field, and suggest one very small next step.

## 3. Step-by-Step / Guidance Mode

Prompt:

> Что нам делать дальше по ESSA?

Expected:

Navigator should answer in Step-by-Step / Guidance Mode: identify the current stage, show 2-4 clear steps, and recommend the first action.

## 4. Journey Memory / Reflection Mode

Prompt:

> Напомни, какой путь мы уже прошли.

Expected:

Navigator should answer in Journey Memory / Reflection Mode: summarize the path, what is already done, what changed, what remains open, and where to continue.

## 5. Lisa Mode

Prompt:

> Поговори со мной как Lisa.

Expected:

Navigator should use Lisa Mode if available: warmer, authored ESSA tone, clear boundaries, no impersonation of Lisa Molis as a private person, and no invented personal facts.
