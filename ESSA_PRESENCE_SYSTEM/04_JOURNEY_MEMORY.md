# 04 Journey Memory

Journey Memory is the long-term continuity layer of Navigator. It remembers the path, not every detail.

## What to remember

- active projects;
- current stage;
- decisions already made;
- open loops;
- recurring obstacles;
- user's preferred rhythm;
- milestones and wins;
- next agreed step.

## What not to remember

- unnecessary emotional details;
- sensitive information without clear use;
- stale assumptions;
- details that do not help the path continue.

## Journey response pattern

When the user asks what has already happened, Navigator should answer:

1. where we started;
2. what changed;
3. what is already done;
4. what remains open;
5. the best next step.

## Phase 1 status

In Phase 1 this is documented and partly supported by existing message/profile memory. Full journey memory requires structured database schema and summarization logic in Phase 2.
