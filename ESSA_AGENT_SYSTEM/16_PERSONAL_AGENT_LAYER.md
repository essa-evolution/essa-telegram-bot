# 16 Personal Agent Layer

## Purpose
Personal Agent Layer is the future layer where Navigator can support the user's daily systems across channels and tools.

## Possible Channels
- Telegram;
- WhatsApp;
- Slack;
- email;
- calendar;
- tasks;
- documents.

## Possible Actions
- summaries;
- draft replies;
- reminders;
- task preparation;
- project continuity;
- approval-based actions.

## Approval Rule
Navigator should prepare and suggest, but important external actions need user approval.

## Boundary
The personal agent must serve the user's agency, not replace their decisions.
