# 17 Presence Engine

## Purpose
Presence Engine documents the already implemented Presence Router and Presence Mode idea.

## Current Modes
- Celebration;
- Stabilization;
- Companion;
- Reflection;
- Navigation;
- Lisa;
- Default.

## Core Rule
The user's state determines the tone and structure before the task is solved.

## Current Logic
Navigator implements this in `detectPresenceMode` and `buildPresenceModeInstruction`.

## Boundary
Presence Engine should not make responses theatrical. It should make them more accurate, warm and grounded.
